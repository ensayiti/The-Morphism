# The Morphism — Design Skill

This project uses **The Morphism**: an agent-agnostic aesthetic design skill. Follow it whenever the task involves UI design work.

## Source of truth

Read `skills/the-morphism/SKILL.md`. It contains:

- The **Design Read** workflow — read the brief, declare the style, set four dials (DEPTH / SOFTNESS / TRANSLUCENCY / GLOW)
- **Eight exact CSS recipes + Tailwind v4 equivalents**: Glassmorphism, Futurism, Neubrutalism, Brutalism, Minimalism, Maximalism (Morph Design); Swiss Design, Bauhaus (Non-Morph)
- **Named anti-patterns** (the tells), a motion system, a typographic scale (two font tracks: shadcn/Next Geist or Fontshare)
- Deeper reference material in `skills/the-morphism/references/`

## Non-negotiable

- One style per page. Never mix.
- Zero em-dashes anywhere visible to the user. Zero emoji as icons.
- The recipes are exact. The rules are opinionated. The bans are named.
