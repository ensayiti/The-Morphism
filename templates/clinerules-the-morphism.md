# The Morphism — Design Skill (Cline / Roo)

**The Morphism** is an agent-agnostic aesthetic design skill. Apply it to all UI design work in this project.

Read `skills/the-morphism/SKILL.md` — the source of truth: eight exact styles with CSS recipes and Tailwind v4 equivalents (Glassmorphism, Futurism, Neubrutalism, Brutalism, Minimalism, Maximalism, Swiss Design, Bauhaus), named anti-patterns, a motion system, and a typographic scale with two font tracks. Reference material lives in `skills/the-morphism/references/`.

## Non-negotiable

- One style per page. Never mix.
- Zero em-dashes anywhere visible to the user. Zero emoji as icons.
- The recipes are exact. The rules are opinionated. The bans are named.
